The current version of the game is V0.1-alpha, which is the first ever alpha release and is used as an internal resource for alpha-testing with our (minimal) staff (of 2 people).

We are looking for alpha-testers! Please email Ella/Grombovii at ella.the.jordan@gmail.com and let us know if you are interested! Alpha-testing takes place over Discord voice chat, generally between the hours of 8:00PM and 11:30PM, with sessions usually lasting 1-3 hours.
